# 43 FAMILY ROLEPLAY | EMS Promotion Exam System (Season 2)

Official web-based examination portal for the Emergency Medical Services department in 43 Family Roleplay Season 2.

## Features
- **Strict Roleplay Focus:** Tailored FiveM server questions covering protocols, radios, scripts, and scene control.
- **Anti-Repeat Algorithm:** Intelligent question-rotation ensuring candidates do not receive identical exam sets.
- **Multi-Language Support:** Instant switching between English, French, and Arabic (with complete RTL support).
- **Secure Admin Panel:** Protected by password (`0112`) to review candidate scores, history, and detailed answer sheets.
- **GitHub Ready:** Fully static single-file application ready for instant deployment on GitHub Pages.

## Deployment Instructions for GitHub Pages
1. Create a new repository on GitHub (e.g., `ems-promotion-system`).
2. Upload `index.html`, `package.json`, and `README.md` to the main branch.
3. Go to your repository **Settings** -> **Pages**.
4. Under **Build and deployment**, select **Deploy from a branch** (`main` / root `/`).
5. Your application will be live instantly!
